# MobileVitals.org

A modern, responsive website for Mobile Vitals - quality signals for mobile development, inspired by Web Vitals.

## Features

- **Modern Design**: Clean, professional design similar to web.dev
- **Platform Toggles**: Interactive tabs to switch between Android and iOS implementations
- **Color-coded Thresholds**: Performance thresholds highlighted in green (good), yellow (meh), and red (bad)
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Subtle animations and hover effects
- **Code Copy**: One-click copy functionality for code samples
- **Smooth Scrolling**: Navigation with smooth scrolling to sections

## Structure

- `index.html` - Main HTML structure
- `styles.css` - Modern CSS styling with responsive design
- `script.js` - JavaScript for interactivity and animations
- `mobile-vitals-logo.png` - Logo image

## Getting Started

1. Clone or download the repository
2. Open `index.html` in a web browser
3. The website will load with all functionality ready to use

## Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge

## Features in Detail

### Platform Tabs
Each metric includes Android and iOS implementations that can be toggled using the tab buttons. The content switches smoothly between platforms.

### Performance Thresholds
- **Good** (green): 200ms - 1s
- **Meh** (yellow): 1s - 3s  
- **Bad** (red): >3s

### Code Samples
All code blocks include syntax highlighting and a copy button for easy code sharing.

### Navigation
Sticky header with smooth scrolling navigation to different sections of the website.

## Customization

The website can be easily customized by modifying:
- Colors in `styles.css` (search for color values)
- Content in `index.html`
- Functionality in `script.js`
